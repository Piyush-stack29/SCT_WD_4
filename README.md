# SkillCraft Technology - Task 4

## To-Do Web Application

This project is developed as part of the SkillCraft Technology Web Development Internship.

## Features

- Add New Tasks
- Edit Existing Tasks
- Delete Tasks
- Mark Tasks as Completed
- Undo Completed Tasks
- Set Date & Time for Tasks
- Task Statistics (Total, Completed & Pending)
- Responsive Design
- Local Storage Support (Tasks remain saved after page refresh)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.


## Project Output

The To-Do Web Application allows users to:

- Create new tasks
- Assign a date and time to each task
- Edit task details
- Delete unwanted tasks
- Mark tasks as completed or undo completion
- View total, completed, and pending task counts
- Automatically save tasks using Local Storage
- Access tasks even after refreshing the browser
